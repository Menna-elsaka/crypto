This project demonstrates the implementation and exploration of various cryptography algorithms, including:

Blake2b
Caesar Cipher
Vigenère Cipher
Stream Cipher
Hill Cipher
One-Time Pad (OTP)
Substitution Cipher

Description
This project aims to provide:

Educational examples of each algorithm.
Interactive exploration of classic and modern cryptography techniques.
Reference links and source code for further study.
